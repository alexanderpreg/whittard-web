# 🔄 TAREA: Migrar Formulario de Checkout a React Hook Form + Zod

## 📌 Contexto

Para optimizar el rendimiento del Checkout, evitar re-renders innecesarios mientras el usuario escribe y asegurar validaciones estrictas (DNI, Teléfono, Email) antes de crear la orden, debemos migrar la gestión del formulario actual (`useState`) hacia **React Hook Form + Zod**.
